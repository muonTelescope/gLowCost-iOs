## Visual system (user decision, mockup updated; Swift code NOT yet updated — ask user before porting)
"Violet & phosphor": ground #120E1A, panel #1C1628 (faint top sheen #231C33→#1C1628), raised #261E35, hairline #3A2F4F, bright edge #5E4A93 (hero, selected), ink #EEE9F5, muted #A89CBF; violet #9B7BFF (structure, pressure; primary buttons #AE93FF→#8462F0 with #C9B6FF edge), lilac #C9B6FF (muon tracks), phosphor green #5BE3A0 (live counts, bars, physics state, temperature), overdue pink #FF8FB1. Rate-coloured map ramp is green.
Fonts: Raleway (titles 800, headings 600–700, body 500, lining figures) + IBM Plex Mono (counts, units, caps labels).
Corners chamfered: panels cut top-right/bottom-left 14 px; buttons, chips, tab bar all four corners (4–10 px). A 1 px hairline follows every cut, including the diagonals (mockup draws it as a separate ring layer, not border + clip-path, which clipped the border). Frosted glass only on floating bars (tab bar, logging bar), tooltips and sheets; subtle gradients (hero fade behind the count, panel sheen, primary buttons). System-owned shapes (Dynamic Island, Live Activity, widget and Control Center outlines, lock-screen circular widgets) keep Apple's shapes.
Channel notation: CH with first paddle as superscript and second as subscript (CH⁰₁, CH⁰₂, CH¹₂); the sum is "Σ CH".
One version only (user rejected multiple variations).

## Decisions
- iOS 26+, Tab API, tabViewBottomAccessory logging bar. Friendly default + Expert mode.
- Raw counts only. In-app pressure/temperature corrections removed (detector does SiPM bias temperature compensation; P/T stored per minute).
- Runs in SwiftData (Run/Minute/RunEvent). Rename; live-run rename sends BLE `label` (firmware renames active muon_/env_ SD files; sanitize mirrors firmware, 32 chars). Default tag groups (Power, Radio, Place, Purpose) + custom tags.
- Per-minute GPS → track coloured by rate; altitude chart; event markers; chart scrub moves map marker.
- Improvements implemented: event markers, health check (detrended Fano per pair; Sep 23 mains Wi-Fi-on CH02 = 1.29, clean runs 0.90–1.04), local alerts, SD gap fill over BLE + CSV import (old/new formats), compare runs, Siri/App Shortcuts, share card, VoiceOver labels.
- Storage: user-picked folder (iCloud Drive/cosmic) via security-scoped bookmark → cosmic/phone/<yyyy-MM-dd_HHmm_name>/minutes.csv + run.json, every 5 min.
- Free Apple account: Config.xcconfig holds team, bundle ID, App Group (optional).
- Control Center toggle + Physics-run button open the app; Live Activity Stop button is a LiveActivityIntent.
- Project generated by MuonMonitor/tools/generate_project.py; schemes MuonMonitor and MuonMonitor Demo.
